# Supplementary Materials for the Submission

This repository contains the supplementary materials, data, and analysis code for our paper submission.

## Repository Contents

1. **`analyze_results.Rmd`**
   Contains the R code used to process the coded dataset and generate the descriptive statistics reported in the manuscript.

2. **`HRI_Validation_Coding_Data_Paperlevel.csv`**
   Contains the paper-level coding data used in the analysis.

3. **Supplementary Materials**
   The supplementary document includes:
   - additional details on the HRI Experiment Validation Framework;
   - the complete codebook, including variable definitions and operational coding criteria; and
   - additional information on papers whose study settings or robot interaction modalities were coded as involving multiple categories or as not reported
  
4. **Descriptive Results Files**  
   Three CSV files contain the descriptive results generated by the analysis code in `analyze_results.Rmd`using the coding data in `HRI_Validation_Coding_Data_Paperlevel.csv`:
   - **`results_summary_by_dimension.csv`**: descriptive results for the methodological indicators organized by validation dimension;
   - **`results_summary_external_validity.csv`**: descriptive results for indicators related to external validity; and
   - **`results_summary_technical_vs_nontechnical.csv`**: descriptive comparisons between technical and non-technical papers.
